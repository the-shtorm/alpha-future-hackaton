# Локальные данные кредитного скоринга

`raw/` — отдельная папка для неизменённого CSV пользователя. Исходные CSV и
временные представления не входят в Git. В `prepared/` будут отдельные
обучающие представления и manifest с индексами временных разбиений.

Ожидаемый файл: `sba_dataset(2010-2026).csv`, 461 559 строк и 23 колонки.
SHA-256: `eb9efbe801725f70969a1e1128c4ce3b1930c4f34e8820d3d0b81c84f4951e43`.
Определение цели: `LoanStatus=1` — списан, `0` — погашен.

Полный путь к CSV передаётся CLI. Схема компонентов дат закреплена по полученному
файлу, хеш и все временные когорты проверены 2026-10-25.
Параметры ожидаемой версии: `fastapi/scoring_training/config/dataset.lock.json`.
