# Данные обучения SBA

[Обучение](../../fastapi/scoring_training/README.md) · [Рабочий скоринг](../../docs/credit-scoring.md)

Для запуска приложения используется готовый inference-пакет из HF.
Этот каталог предназначен для воспроизведения обучения и анализа датасета.

`raw/` содержит неизменённый исходный CSV, `prepared/` — подготовленные
представления, индексы временных разбиений и manifest. CSV и большие
промежуточные файлы игнорируются Git.

Ожидаемая версия: `sba_dataset(2010-2026).csv`, 461 559 строк, 23 колонки,
SHA-256 `eb9efbe801725f70969a1e1128c4ce3b1930c4f34e8820d3d0b81c84f4951e43`.
`LoanStatus=1` означает списание, `0` — погашение. Полный путь передаётся CLI.
Хеш, схема, цель и состав временных когорт закреплены в
`fastapi/scoring_training/config/dataset.lock.json`. Подготовка сверяет lock
и создаёт новый каталог результата, сохраняя исходные данные.
