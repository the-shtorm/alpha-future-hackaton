# Local E5 credit-semantics experiment

This is a [sentence-transformers](https://www.SBERT.net) model trained. It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
<!-- - **Base model:** [Unknown](https://huggingface.co/unknown) -->
- **Maximum Sequence Length:** 512 tokens
- **Output Dimensionality:** 384 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text
<!-- - **Training Dataset:** Unknown -->
- **Language:** ru
- **License:** mit

### Model Sources

- **Documentation:** [Sentence Transformers Documentation](https://sbert.net)
- **Repository:** [Sentence Transformers on GitHub](https://github.com/huggingface/sentence-transformers)
- **Hugging Face:** [Sentence Transformers on Hugging Face](https://huggingface.co/models?library=sentence-transformers)

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'BertModel'})
  (1): Pooling({'embedding_dimension': 384, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
queries = [
    'query: Цель финансирования — исполнение контракта. Деньги нужны одной суммой. Дополнительные обстоятельства: Контекст обращения: Поставляем расходные материалы по заключённому контракту, деньги нужны для исполнения поставки. Деньги используем для указанной задачи, без изменения назначения.',
]
documents = [
    'passage: Тип финансирования — кредит с разовой выдачей. Назначение — исполнение контракта. Средства предоставляются одной суммой. Сценарий применения: Финансирование исполнения контракта. Имущественный залог не требуется. Требование к поручительству зависит от условий сделки. Для ООО требуется поручительство контролирующего владельца; для ИП в DEMO не требуется.',
    'passage: Тип финансирования — кредит с разовой выдачей. Назначение — пополнение оборотных средств. Средства предоставляются одной суммой. Сценарий применения: Разовое пополнение оборотных средств. Имущественный залог не требуется. Требование к поручительству зависит от условий сделки. Для ООО требуется поручительство контролирующего владельца; для ИП в DEMO не требуется.',
    'passage: Тип финансирования — кредит с разовой выдачей. Назначение — развитие бизнеса и инвестиции. Средства предоставляются одной суммой. Сценарий применения: Инвестиции и развитие под залог недвижимости. Имущественный залог требуется. Требование к поручительству зависит от условий сделки. Для ООО требуется поручительство контролирующего владельца; для ИП в DEMO не требуется.',
]
query_embeddings = model.encode_query(queries)
document_embeddings = model.encode_document(documents)
print(query_embeddings.shape, document_embeddings.shape)
# [1, 384] [3, 384]

# Get the similarity scores for the embeddings
similarities = model.similarity(query_embeddings, document_embeddings)
print(similarities)
# tensor([[0.6285, 0.3769, 0.2872]])
```
