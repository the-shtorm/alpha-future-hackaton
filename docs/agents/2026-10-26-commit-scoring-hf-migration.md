загрузка scoring из HF/локальной папки, постоянный кэш, проверки, конфигурация

Секретные `.env`, резервные копии и скачанные модели/кэши игнорируются и в commit
не включаются. Предыдущие отчёты сохранены без переписывания:

- [HF migration и 536 Linux tests](2026-10-26-scoring-hf-parameterized-source.md).
