# Реализация кредитного скоринга SBA

Дата: 2026-10-25. Статус: выполняется, исходный CSV ещё не предоставлен.

## Запрос и ограничения

Реализовать модель по `docs/credit-scoring-implementation-plan.md`. Разбить работу
на подзадачи и делать локальные коммиты; ничего не отправлять в remote. Когда
понадобятся обучающие данные, запросить CSV у пользователя и сохранить его в
отдельную папку. Сохранять E5, публичные формы, исторические решения и платежи.
Не выдавать тестовые модели или синтетические данные за обученный SBA-пакет.

## Подзадачи

1. Контракт, справочники, manifest датасета и общая подготовка признаков.
2. Воспроизводимые эксперименты, калибровка, оценка и проверяемый пакет модели.
3. Изолированный runtime скоринга и FastAPI, выключенный по умолчанию.
4. Java gateway, новая версия политики, аудит, совместимость старых ревизий.
5. Реальное обучение, offline/HTTP/сквозная приёмка и эксплуатационные измерения.

Зависимость: обучение и итоговая активация требуют исходного CSV и успешных
критериев выпуска. Последовательность выпуска и ограничения заданы планом.

## Подзадача 1: контракт и единые признаки

Созданы `fastapi/app/scoring/contracts.py`, `features.py`, два JSON Schema и
экспортёр схем. Опубликован строгий контракт `sba-scoring-1`: девять признаков,
UUID, decimal strings, строгие int/Boolean, enum, запрет лишних полей. Ответ
проверяет конечную вероятность и соответствие балла с ROUND_HALF_UP. Endpoint
пока не подключён, изменения публичного API приложения и БД отсутствуют.

Общий CSV/HTTP-преобразователь сохраняет только явный список признаков, хранит
категории строками, поддерживает полный NAICS/двузначный префикс. Ставка 28%
остаётся 28; календарные и outcome-поля в X не входят. Категории возраста
согласованы с `docs/reference/data-policy-3.0.md`, включая широкие исторические.
Обучающая популяция не фильтруется по HTTP-ограничению срока 360 месяцев.

Создано отдельное CPU-окружение `fastapi/scoring_training/pyproject.toml` и
`uv.lock`: Python 3.11.14, CatBoost 1.2.10, sklearn 1.9.1, pandas 2.3.3.
Окружения/lock E5 и checkpoint не менялись. Созданы `data/scoring/raw/` и
`prepared/` с исключением данных из Git. `dataset.lock.json` закрепляет хеш,
количество строк/колонок, классы и когорты из плана; точные названия компонентов
дат намеренно ожидают получения исходного CSV (`schemaStatus=awaiting-source-header`).
