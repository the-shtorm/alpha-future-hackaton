# Query и passage в действующей рекомендательной системе

[Навигация](README.md) · [Обмен Java/FastAPI](ranking-exchange.md) · [Передача E5](../fastapi/MODEL_HANDOFF.md)

FastAPI собирает русские тексты по детерминированным шаблонам, кодирует их
дообученной `multilingual-e5-small` и вычисляет cosine similarity нормализованных
эмбеддингов. Spring предварительно проверяет числовые ограничения продукта.
Версия обмена — `query-passage-mvp-2`, смыслового каталога — `synthetic-semantics-1`.

## Query

Текст потребности собирается из шести полей:

| Поле | Использование |
|---|---|
| `business.sector` | Подпись отрасли из общего словаря |
| `request.purpose` | Цель кредита |
| `request.usageMode` | Разовая выдача, использование частями или резерв |
| `request.description` | Уточнение до 500 символов |
| `security.collateralReady` | Готовность обсуждать залог |
| `security.guarantorReady` | Готовность привлечь поручителя |

Неизвестные значения пропускаются в тексте. Свободное описание обрабатывается
как данные. Словари доступны через `GET /forms/preliminary/dictionaries`.
Числовые значения суммы, срока и выручки используются проверками применимости.
Тексты получают префикс E5 `query: `.

## Passage

Для продукта используются название, тип, цели, способ использования, сценарий,
целевые отрасли, специализация и отдельные условия залога и поручительства.
Эти данные закреплены в синтетическом каталоге и снимке запроса Java.
Текст получает префикс `passage: `. Эмбеддинги продуктов кэшируются с учётом
версии модели, шаблона и содержимого продукта.

## Результат

Возвращаются все переданные кандидаты с непрерывными рангами и
`similarityScore` в `[-1, 1]`. `topK=3` задаёт максимум выделенных рекомендаций;
активный порог cosine distance дополнительно определяет их пригодность.
На экране score показывается десятичной оценкой сходства. Банковское решение
рассчитывается отдельным этапом [SBA-скоринга](credit-scoring.md).

Версии модели и обоих шаблонов сохраняются с результатом. Изменение формы или
активной версии продукта требует нового подбора. Точный HTTP-контракт и
JSON Schema: [ranking-exchange.md](ranking-exchange.md).
Первоначальное предложение контракта сохранено как
[исходный материал](reference/query-passage-mvp-source.md).
