# Предварительная форма подбора кредита и источники данных

**Версия 3 от 20 октября 2026 года.** Для предпринимательских кредитов ИП и ООО в России.

**Сценарий:** заявитель вводит ИНН → система подставляет доступные сведения о бизнесе → заявитель подтверждает бизнес, указывает потребность и текущие финансы → система подбирает продукты.

Это предварительный подбор, а не кредитное решение. Паспорта, кредитные отчеты и другие файлы здесь не загружаются.

## Источники данных

| Обозначение | Что означает | В хакатоне |
|---|---|---|
| **Заявитель** | Самостоятельный ввод или подтверждение фактических сведений | Пользователь заполняет форму на синтетическом примере |
| **Реестр ФНС** | ЕГРЮЛ/ЕГРИП: регистрационные сведения | Локальный симулятор с синтетическими ответами |
| **Реестр МСП** | Единый реестр субъектов малого и среднего предпринимательства ФНС | Отдельный локальный симулятор |
| **Данные банка** | Актуальное досье выбранной организации, ее счета и известные банку обязательства; только при наличии права доступа | Профиль синтетического демоклиента |
| **Система** | Расчет по исходным значениям и правилам каталога | Версионированные правила 15 тестовых предложений |

При работе с реальными источниками нужно отдельно выбрать доступный и разрешенный способ интеграции. Публичный сайт не означает наличие бесплатного промышленного API. Демонстрация должна работать без внешней сети.

## Шаг 1 Найдите и подтвердите бизнес

### Первое поле

**ИНН бизнеса:** `[Введите ИНН]`

Кнопки: **«Найти бизнес»** / **«Продолжить без ИНН»**.

ИНН вводит заявитель либо система подставляет его из выбранной организации в авторизованном кабинете. При анонимном подборе его можно пропустить; при сохранении организации и подаче заявки он потребуется.

Проверяем формат и контрольные разряды: 10 цифр для ООО, 12 для ИП. Такая проверка сама по себе не подтверждает существование бизнеса.

### Карточка найденного бизнеса

| Поле | Откуда берем | Что делает заявитель |
|---|---|---|
| Форма бизнеса — ИП или ООО | Реестр ФНС; для существующего клиента возможно актуальное досье банка | Подтверждает выбранный бизнес |
| Наименование ООО или ФИО ИП | Реестр ФНС | Проверяет, что выбрана нужная организация или ИП |
| ИНН, ОГРН/ОГРНИП | Реестр ФНС | Повторно не вводит |
| Дата государственной регистрации | Реестр ФНС | При расхождении сообщает об этом |
| Зарегистрированный основной ОКВЭД | Реестр ФНС | Далее подтверждает фактическую деятельность |
| Регистрационный статус | Реестр ФНС | При расхождении оставляет пояснение; не может самостоятельно объявить проверку пройденной |
| Юридический адрес ООО | Реестр ФНС | Проверяет; фактическое место работы указывает отдельно |
| Наличие в реестре МСП и категория | Реестр МСП | Может сообщить о расхождении |

Кнопки: **«Это мой бизнес»** / **«Выбрать другой»** / **«Есть расхождение»**.

Адрес проживания ИП в предварительной форме не собираем. Юридический адрес ООО не используем вместо фактического региона работы.

### Фактические сведения

| Вопрос | Поле и ответы | Откуда берем | Обязательность |
|---|---|---|---|
| Где фактически работает бизнес | `[Регион и город]`; `Работаем в нескольких регионах` | Заявитель. Из досье можно предложить ранее указанный вариант для подтверждения | Нужно указать |
| Чем занимаетесь сейчас | `[Категория или описание]`; `Совпадает с данными реестра` | Зарегистрированный ОКВЭД подставляет система; фактическую деятельность подтверждает заявитель | Нужно указать; точный код можно уточнить позже |
| Когда фактически начали работать | `[Месяц и год]`; `С момента регистрации`; `Не знаю` | Заявитель | Уточнение, если отличается от регистрации |
| Какой налоговый режим применяется | `ОСНО / УСН / ПСН / АУСН / НПД для ИП / Совмещение разрешенных режимов / Другой / Не знаю` | Заявитель; актуальные сведения досье или доступные сведения ФНС — подсказка для подтверждения | Нужен ответ; «не знаю» допустимо |

**Если ИНН не указан или источник недоступен:** заявитель выбирает ИП/ООО, указывает дату регистрации либо «не знаю», описывает деятельность. Наименование для анонимного подбора необязательно. Недостающие регистрационные реквизиты не выдумываем. Значения отмечаем как указанные заявителем, а не полученные из реестра.

Доступные сведения о налоговом режиме могут иметь ограничения по охвату и дате. Отсутствие сведений о спецрежиме нельзя автоматически считать подтверждением ОСНО.

## Шаг 2 Укажите потребность в финансировании

Все сведения этого шага сообщает **заявитель**: внешние источники не знают его желаемые условия новой сделки.

| Вопрос | Поле и ответы | Обязательность |
|---|---|---|
| Для чего нужны деньги | `Оборотные средства / Кассовый разрыв / Оборудование / Транспорт / Коммерческая недвижимость / Исполнение контракта / Рефинансирование / Развитие или инвестиции` | Нужно указать |
| Какая сумма нужна | `[Сумма] ₽` | Нужно указать |
| На какой срок | `[Число] месяцев` | Нужно указать |
| Как планируете пользоваться деньгами | `Одна сумма / Лимит частями / Запас средств на расчетном счете / Пока не знаю` | Нужен ответ; «пока не знаю» допустимо |
| Когда понадобится финансирование | `[Дата или месяц]`; `Не срочно` | Необязательно |

Для линии и овердрафта сумма означает желаемый лимит задолженности. Срок лимита и срок отдельного транша — разные параметры; детали уточняются в полной заявке.

## Шаг 3 Укажите финансы и доступные условия

### Основные вопросы

| Вопрос | Поле и ответы | Откуда берем на этапе подбора | Обязательность |
|---|---|---|---|
| Какова средняя выручка за месяц | `[Сумма] ₽`; `Не знаю`; период `[с] — [по]`, число полных месяцев | Заявитель. Банк может предложить расчет по доступным данным после классификации операций и с подтверждением охвата | Нужен ответ; «не знаю» допустимо |
| Есть ли сезонность | `Почти нет / Умеренная / Сильная / Не знаю` | Заявитель; при наличии достаточной доступной истории можно предложить подсказку | Нужен ответ; «не знаю» допустимо |
| Каков остаток бизнес-долгов | `[Сумма] ₽`; `Долгов нет`; `Не знаю` | Заявитель. Известный долг в своем банке можно показать отдельно, но он не равен всему долгу | Нужен ответ; «не знаю» допустимо |
| Сколько платите по долгам в месяц | `[Сумма] ₽`; `Платежей нет`; `Не знаю` | Заявитель; платежи по собственным кредитам банка — только часть общей нагрузки | Нужен ответ; «не знаю» допустимо |
| Есть ли текущие просрочки | `Нет / По кредитам и займам / По налогам / Другие / Не знаю` | Заявитель. Доступные данные банка или ФНС сохраняются как отдельный сигнал с датой | Необязательное уточнение |
| Какой залог готовы обсудить | `Без имущественного залога / Недвижимость / Оборудование / Транспорт / Иное / Пока не знаю` | Заявитель | Нужен ответ, включая неопределенный вариант |
| Готовы ли привлечь поручителя | `Да / Нет / Готов обсудить` | Заявитель | Нужен ответ, включая «готов обсудить» |

Для выручки желательно использовать последние 12 полных месяцев; при короткой истории — фактический период. Это политика MVP, а не общий срок закона.

**Поступления на счет не равны выручке.** Кредиты, взносы собственников и переводы между своими счетами не считать продажами. Годовую отчетность нельзя просто разделить на 12 и представить как подтвержденную текущую месячную выручку.

### Условные вопросы

| Когда показываем | Вопрос и поля | Откуда берем |
|---|---|---|
| Покупка имущества или проект с собственным участием | Стоимость покупки/проекта `[сумма] ₽`; собственные средства `[сумма] ₽`; `Пока не знаю` | Заявитель; документы и наличие средств подтверждаются позднее |
| Исполнение контракта | Контракт `Подписан / Согласовывается / Отсутствует` | Заявитель; файл контракта на этом этапе не нужен |
| Продукт с условием счета или оборотов | Счет в банке `Есть / Нет / Готов открыть`; дата открытия | Внутренние данные банка для авторизованного действующего клиента; иначе заявитель |
| Продукт для продавцов маркетплейсов | Площадка `[название]`; длительность продаж `[месяцев]`; `Не знаю` | Заявитель; отчеты продаж получают позднее по разрешенной интеграции или из документов |

Если условие неизвестно, можно показать продукт с пометкой «потребуется подтвердить». Неизвестное не считается выполненным условием.

## Что рассчитывает система

| Значение | Из чего рассчитываем | Ограничение |
|---|---|---|
| Стаж с регистрации | Дата регистрации + дата расчета | Не подменяет фактический опыт работы |
| Предварительная применимость продукта | Сведения формы + правила каталога | Учитывать, какие сведения еще не проверены |
| Доля собственных средств | Собственные средства / стоимость покупки или проекта | Только при известных значениях и положительной стоимости |
| Примерный платеж | Сумма, срок и известные условия продукта | Для линии/овердрафта нужен сценарий использования; расчет не является окончательными условиями |
| Порядок рекомендаций | Применимость, цель, параметры и предпочтения | Рейтинг рекомендации не является вероятностью одобрения |

## Какие проверки оставляем полной заявке

- **Основная часть кредитной истории:** запрашивается банком по надлежащему согласию соответствующего субъекта; простой ввод ИНН такой запрос не запускает.
- **Счета и операции других банков:** не являются публичными; нужны доступная интеграция, необходимые полномочия и надлежащее согласие клиента.
- **Паспортные данные, поручители и залогодатели:** собираются по применимому сценарию рассмотрения.
- **Право собственности и обременения залога:** проверяются, если обеспечение требуется для сделки.
- **Отчетность, выписки и целевые документы:** запрашиваются или получаются по динамическому чек-листу.

## Как храним и показываем происхождение

Для каждого значения сохраняем:

- значение и организацию/субъект, к которому оно относится;
- источник;
- дату получения и дату или период актуальности, если известны;
- статус проверки;
- ссылку на исходный ответ или документ;
- отдельно — подтверждение заявителем, уточнение и причину расхождения.

Примеры подписей в интерфейсе:

> Получено из ЕГРЮЛ · дата получения

> Указано заявителем · не проверено

> Рассчитано системой · на основе указанных данных

> Данные не получены

Подтверждение пользователем не меняет происхождение данных. Его уточнение не перезаписывает незаметно официальный ответ источника.

**Неизвестное значение не равно нулю.** Сбой сервиса, отсутствие записи и явный отрицательный результат — разные состояния. Если источник недоступен, допускаем ручной ввод для подбора, сохраняя соответствующую отметку.

В демоверсии ответы симуляторов подписываем **«Демонстрационные сведения»**. Они не должны выглядеть как результат настоящей проверки ФНС или банка.

## Завершение формы

Кнопка: **«Подобрать предложения»**.

Результат: продукты с объяснением подбора, примерными параметрами и перечнем неподтвержденных условий.

Текст под результатом:

> Подбор выполнен по доступным сведениям и вашим ответам. Условия и решение по кредиту определяются после рассмотрения заявки.

При обработке ИНН ИП и других персональных данных нужно определить законное основание обработки и предоставить необходимую информацию о ней. Маркетинговое согласие не является условием подбора. Доступ к закрытым источникам не разрешается одним нажатием «Найти бизнес».

## Источники и условия интеграции

- [ФНС — сервисы открытой информации](https://www.nalog.gov.ru/donline/): состав доступных регистрационных сведений и источников.
- [ФНС — электронные сведения ЕГРЮЛ/ЕГРИП](https://www.nalog.gov.ru/rn77/yul/interest/reg_yl/chek_egrip/): получение регистрационной информации.
- [ФНС — «Прозрачный бизнес»](https://pb.nalog.ru/compare.html): дополнительные сведения о бизнесе, включая доступные данные МСП и налогов. Охват и актуальность проверяются для каждого набора.
- [ГИР БО — условия программного доступа](https://bo.nalog.gov.ru/subscriptions-service): возможный источник последующей проверки отчетности, не обязательная интеграция короткой формы.
- [Банк России — открытые API](https://cbr.ru/fintech/api/): обмен банковскими данными и согласия. Наличие стандарта не гарантирует доступ вашему приложению.
