## Ограничения выполненной проверки

Обычный PostgreSQL 17 в Docker и Java/Testcontainers из текущей сессии не проверены: после запуска пользователем Docker его локальный канал `\\.\pipe\docker_engine` доступен с ограничением `permission denied` для этой среды. Запрос разрешения на устройство не поддерживается механизмом путей данной среды. Это ограничение доступа агента, а не утверждение, что Docker пользователя выключен.

Java/Maven сборка выполнена из установленного JBR 25 с целевой версией компиляции 21, а не из установленного JDK 21. Первоначальные попытки остановились из-за `AccessDeniedException` при работе с локальными JAR/каталогом `target`; сборка с отдельным процессом компилятора завершилась с кодом 0. Успешная компиляция не считается выполнением тестов на JVM 21 или проверкой JDBC/Flyway.

WebAssembly-проверка подтверждает исполнение PostgreSQL SQL/PLpgSQL, ограничений и прав в одной сессии, но не подтверждает работу JDBC, Flyway metadata/checksum, конкурентные гонки между соединениями, реальную криптографию, внешний антивирус или реальные банковские операции.

Для полного повторения в среде с доступом к Docker выполните `mvn -f backend/pom.xml test` на JDK 21. В репозитории есть два интеграционных теста: применение миграций/каталога/сценариев и проверка разделения прав. До успешного выполнения они остаются подготовленными, а не пройденными.

## Контейнеризация

Добавлены корневой `Dockerfile`, ограниченный сборочный контекст `.dockerignore`, правила LF для Linux-файлов и сервис `backend` в Compose. Сборка использует Maven/JDK 21, runtime — JRE 21 с UID/GID 10001. Пароли передаются через окружение при запуске. Backend ожидает готовности PostgreSQL; его текущий режим — однократный запуск миграций с последующим завершением.

Обновленная конфигурация успешно прошла `docker compose --env-file .env.example config --quiet`; `git diff --check` не выявил ошибок пробелов. Попытка `docker compose --env-file .env.example build backend` остановилась до сборки из-за запрета доступа этой среды к `\\.\pipe\docker_engine`. Сборка образа и запуск связки контейнеров поэтому пока не подтверждены. Обычный пользователь с доступом к Docker может выполнить команды из README.
